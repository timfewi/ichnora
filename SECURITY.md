# Reporting a security vulnerability

[Report a vulnerability privately on GitHub](https://github.com/timfewi/ichnora/security/advisories/new).
Use this channel for issues such as access across project boundaries or
unexpected exposure of stored session text.

Include the affected Ichnora version or commit, relevant configuration and
adapter, what is exposed or bypassed, and a minimal reproduction with synthetic
data. Omit real transcripts, runtime databases, credentials, and identifying
details from the report.
