Scope and redistribution
------------------------

This bundle covers the production Go modules pinned in go.mod, Go runtime and
standard-library code, and Go-derived code in those modules for the ichnora
executable built by nix/package.nix. It retains module-level licenses even
where the linker can omit unused code. Dependency tests, examples, fuzzing
programs, and documentation are not installed by that recipe. In particular,
this is not a distribution of the MCP SDK's CC-BY-4.0 documentation.

The Nix package installs LICENSE, this file, and the accompanying LICENSES/
directory in share/doc/ichnora. Keep those materials with redistributed binary
packages; license terms and copyright notices are in the referenced files,
not merely at the upstream links below. No license material is downloaded or
generated at runtime or during package installation.

This source release and bundle do not purport to distribute or document the
licenses of an entire Nix system closure. Source-only development tools,
compilers as executables, and separately packaged system libraries retain
their own licenses. Redistributors supplying those additional components
must also supply their applicable notices. SQLite is discussed separately
below because the Nix binary links against libsqlite3.

Provenance and maintenance
--------------------------

The module license files were copied unchanged from LICENSE in the exact
module versions listed above, using the local Go module cache. The shared
Go license and patent files were copied from golang.org/x/sys v0.41.0; the
other listed module copies carry the same text. Supplemental Go source
notices and the reflect/deepequal.go attribution were taken from the locally
installed Go 1.26.7 source tree.

The root LICENSE is the unmodified standard Apache License, Version 2.0 text,
including its appendix. The local copy used as the text source was LICENSE.txt
in github.com/aws/aws-sdk-go-v2 v1.41.0. Only that standard license text was
copied: this does not indicate an AWS SDK dependency or transfer AWS copyrights
to ichnora. The original-project copyright and license grant are above.

When production dependencies, Go toolchain, build tags, or shipped artifacts
change, review the actual upstream license files, source notices, and any
NOTICE/PATENTS files, update this inventory and LICENSES/, and retain the
resulting bundle with the binary. Do not infer licensing from a package name
or a single SPDX label, especially for the MCP SDK's mixed-license transition.
